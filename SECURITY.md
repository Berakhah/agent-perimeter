# Security Policy

Agent Perimeter is a security posture scanner for MCP servers. If you discover a vulnerability in Agent Perimeter itself, please report it privately through GitHub ([Security → Report a vulnerability](https://github.com/Berakhah/agent-perimeter/security/advisories/new)) rather than opening a public issue. We will acknowledge receipt within 24 hours and provide a clear timeline for remediation.

For our coordinated disclosure policy for findings discovered *in scanned servers*, see [docs/security.md](docs/security.md).
