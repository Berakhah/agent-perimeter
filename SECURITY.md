# Security Policy

Agent Perimeter is a security posture scanner for MCP servers. If you discover a vulnerability in Agent Perimeter itself, please report it privately through GitHub ([Security → Report a vulnerability](https://github.com/Berakhah/agent-perimeter/security/advisories/new)) rather than opening a public issue. I aim to acknowledge within 5 business days and to give a remediation timeline once the report is confirmed. This is a one-person project.

For our coordinated disclosure policy for findings discovered *in scanned servers*, see [docs/security.md](docs/security.md).
